# Подробное решение

## 1. Создание пользователей и сайта

**1.1. Создание пользователя netology**

Где: ispmanager → Пользователи → Создать.

| Поле | Значение |
|---|---|
| Имя | netology |
| Пароль | задайте надёжный |
| Email | ваш email |
| Автосоздание объектов | ❌ отключить |
| Доступы | ✅ все пункты, кроме «Может использовать shell» |

Нажмите Создать.

**1.2. Создание пользователя ispmanager**

Повторите п. 1.1 с именем ispmanager и теми же настройками:

Автосоздание объектов — отключено;

Доступы — все, кроме «Может использовать shell».

Нажмите Создать.

**1.3. Создание сайта WordPress для netology**

Где: ispmanager → Сайты → Создать → WordPress.

| Поле | Значение |
|---|---|
| Доменное имя | mk-industrias.online |
| Владелец | netology |
| Тема оформления | любая |
| Логин администратора WP | задайте |
| Пароль администратора WP | задайте |
| Email администратора WP | ваш email |

Нажмите Создать.

<img width="685" height="839" alt="Image" src="https://github.com/user-attachments/assets/59a13eaa-ba4c-4797-9e3f-0f2ba8031e7e" />


💡 Сохраните данные для входа в админку WordPress из всплывающего уведомления (иконка колокольчика в правом верхнем углу): логин, пароль, имя БД, пользователь БД, пароль БД.

<img width="453" height="589" alt="image" src="https://github.com/user-attachments/assets/5cd88ce1-5176-44e9-ba4b-e676547accc9" />

Если пропустили — контекстное меню сайта → WordPress → данные отобразятся заново.

**1.4. Проверка работы сайта**

Откройте сайт в браузере: http://mk-industrias.online/.

Убедитесь, что открывается главная страница WordPress.

<img width="2554" height="727" alt="image" src="https://github.com/user-attachments/assets/7ddd03c0-6ce5-4b2a-b1e6-14d477fb8960" />

В ispmanager → Базы данных — убедитесь, что БД сайта создана.

<img width="2225" height="217" alt="image" src="https://github.com/user-attachments/assets/0be6021a-a5fe-4ea9-a375-d2324d41e0b0" />

В ispmanager → Сайты → сайт — статус Активен.

## 2. Скачивание файлов и дампа БД

**2.1. Скачивание файлов сайта**

Где: ispmanager → Сайты → выберите сайт → Файлы сайта.

Перейдите на уровень /var/www/netology/data/www/.

Найдите директорию mk-industrias.online.

Выделите её галочкой.

Нажмите Скачать (или Архив → Скачать).

<img width="2250" height="258" alt="image" src="https://github.com/user-attachments/assets/92b67675-cb5a-40d9-8c5d-4b1c48d2f850" />

Сохраните архив на локальный компьютер.

**2.2. Экспорт базы данных**

Где: ispmanager → Базы данных.

Найдите БД сайта mk-industrias.online.

Нажмите на неё → Дамп → Экспорт.

Браузер скачает .sql-файл.

<img width="2193" height="546" alt="image" src="https://github.com/user-attachments/assets/3cbf95a6-77c9-4b0f-ab93-8f6529c46f4d" />

Сохраните его на локальный компьютер.

## 3. Создание системной резервной копии

**3.1. Ручное создание резервной копии**

Где: ispmanager → Резервное копирование → Создать копию.

Отметьте:

✅ Данные пользователей

**3.2. Проверка**

Дождитесь завершения — статус копии Успешно.

Убедитесь, что в списке появилась новая запись с текущей датой.

## 5. Восстановление из локальных архивов

**5.1. Восстановление файлов сайта**

Где: ispmanager → Сайты → сайт → Файлы сайта.

Перейдите на уровень /var/www/netology/data/www/.

Нажмите Закачать → выберите ранее скачанный архив.

Дождитесь загрузки.

Выделите архив → Извлечь.

Если распаковалось во вложенную директорию:

Зайдите в неё.

Выделите все файлы → Копировать.

Отметьте «Перенести файлы».

Укажите путь /var/www/netology/data/www/mk-industrias.online/.

<img width="2212" height="443" alt="image" src="https://github.com/user-attachments/assets/373879dd-0588-49a6-95df-594279dc5ae0" />

Нажмите ОК.

**5.2. Создание новой базы данных**

Где: ispmanager → Базы данных → Создать.

| Поле | Значение |
|---|---|
| Имя БД | то же, что было удалено |
| Владелец | netology |
| Пароль | тот же, что был |

Нажмите Создать.

💡 Имя и пароль БД можно взять из сохранённых данных входа в WordPress (п. 1.3).

**5.3. Импорт дампа**

Где: ispmanager → Базы данных → выберите БД → Дамп → Импорт.

Нажмите Выбрать файл → укажите ранее скачанный .sql.

Нажмите Импорт.

⚠️ Важно: при импорте текущие данные БД заменяются данными из дампа.

**5.4. Проверка**

Откройте сайт в браузере — он должен работать.

## 7. Сценарий 2: Имитация сбоя и восстановление из системной копии

**7.1. Удаление пользователя ispmanager**

Где: ispmanager → Пользователи → выберите ispmanager → Удалить.

Подтвердите удаление.

<img width="2284" height="743" alt="image" src="https://github.com/user-attachments/assets/620be28a-d5c9-48e7-81f2-aa28293dd452" />

⚠️ Удаление пользователя удалит все его ресурсы, включая сайт и БД.

**7.2. Проверка «сбоя»**

Откройте сайт в браузере — он не работает.

В ispmanager → Сайты — сайта нет.

В ispmanager → Пользователи — пользователя ispmanager нет.

**7.3. Восстановление из системной копии**

Где: ispmanager → Резервное копирование.

Найдите копию, созданную в п. 3.1.

Нажмите на неё → Восстановить.

Отметьте:

✅ Данные пользователей

✅ Системные файлы

<img width="2237" height="740" alt="image" src="https://github.com/user-attachments/assets/56de8b64-213b-4f48-8c04-d357e7d0cdd9" />

Нажмите Восстановить.

⚠️ Восстановление вернёт данные на момент создания копии. Все изменения после этого будут потеряны.

**7.4. Проверка восстановления**

В ispmanager → Пользователи — пользователь netology снова существует.

В ispmanager → Сайты — сайт восстановлен, владелец — netology.

Откройте сайт в браузере — он работает.

В ispmanager → Базы данных — БД сайта на месте.
