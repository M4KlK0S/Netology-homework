# Отчёт по Проектной работе «Построение инфраструктуры “под ключ”»

## 1. Описание инфраструктуры

**1.1. Хостинг и операционная система**

Проект развернут на виртуальной машине в облачной платформе Yandex Cloud. В качестве операционной системы используется Ubuntu 26.04 LTS. Управление сервером, сайтами и почтовыми сервисами осуществляется через панель хостинга ispmanager.

**1.2. Доменное имя и DNS**

За основным доменом закреплено имя mk-industrias.online. Управление DNS-зоной делегировано регистратору Reg.ru (используются NS-серверы ns1.reg.ru и ns2.reg.ru).

**1.3. Веб-сервисы и почта**

На сервере развернут сайт на базе CMS WordPress. Для безопасного соединения настроен SSL-сертификат от Let's Encrypt.

Параллельно с веб-сервером функционирует почтовый сервер (Exim), настроенный для приема и отправки корреспонденции. Созданы и активно используются почтовые ящики:
- support@mk-industrias.online (с автоответчиком)
- noreply@mk-industrias.online (для транзакционных писем).

**1.4. Сетевая безопасность и доступ**

Доступ к серверу по протоколу SSH защищен комплексом мер: 
- стандартный порт 22 изменен на нестандартный 2222, 
- вход по паролю отключен
- авторизация выполняется строго по криптографическим SSH-ключам.

Дополнительно доступ ограничен фильтрацией по IP. 

Внутренний адрес сервера (192.168.10.18) скрыт за NAT облачной платформы, а публичный IP (51.250.87.95) корректно привязан к почтовому серверу для прохождения проверок обратной зоны (PTR).

Для комплексной защиты инфраструктуры также настроены: 
- ограничение частоты запросов на уровне веб-сервера Nginx (защита от DDoS),
- служба Fail2ban для блокировки подозрительных IP-адресов при попытках несанкционированного доступа (SSH, панель, почта)
- полный набор почтовых записей (SPF, DKIM, DMARC) для подтверждения подлинности домена и защиты от подделок.
