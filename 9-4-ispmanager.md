## 1. Меню настроек и опции для защиты от DoS/DDoS

Где: ispmanager → Сайты → выберите сайт → Изменить → блок «Оптимизация и защита от DDoS» (или при создании сайта) .

Доступные опции (для Nginx):

| Опция | Описание | Для чего |
|---|---|---|
| Включить защиту от DDoS | Активирует модуль `ngx_http_limit_req_module` | Базовая защита |
| Количество запросов в секунду (rate) | Максимум запросов от одного IP за секунду | Защита от нераспределённых атак (один IP) |
| Максимальный размер всплеска (burst) | Максимум запросов в очереди от одного IP | Сглаживание пиков |

Обоснование выбора:

- Для нераспределённой атаки (один источник): параметры rate и burst эффективно ограничивают нагрузку от конкретного IP. Nginx блокирует IP полностью при превышении лимитов.
- Для распределённой атаки (ботнет): на уровне панели защита работает только по ключу $binary_remote_addr (один IP), поэтому от распределённых атак она не спасает — нужна защита на уровне провайдера или сервисы вроде DDoS-Guard.

## 2. Настройка root и панели

Где: ispmanager → Настройки системы и Настройки пользователя root.

Что настроить:
- Двухфакторная аутентификация (2FA) для root: Настройки пользователя → включить 2FA (Google Authenticator) .

- Смена пароля root на сложный (12+ символов).
- Отключение лишних доступов в настройках пользователя.

## 11. Параметры SSH

Где: SSH-доступ к серверу → файл /etc/ssh/sshd_config.

Изменения:

```bash
Port 2222                    # изменить порт (например, на 2222)
PermitRootLogin no           # запретить логин root
```
Применить:
```bash
sudo systemctl restart sshd
```
Итог: содержимое файла /etc/ssh/sshd_config.

## 12. Защита Exim, Dovecot, FTP и SSH

Где: ispmanager → Система → Сетевые службы .

Действия:
- Для каждой службы (Exim, Dovecot, FTP, SSH): выбрать → Правила fail2ban → Изменить → включить правило.
- Для SSH дополнительно: в конфиге Fail2ban указать изменённый порт (из Шага 11).

Где править конфиг Fail2ban:

```bash
sudo nano /etc/fail2ban/jail.local
```
Добавить для SSH:
```ini
[sshd]
port = 2222
```
Перезапустить:
```bash
sudo systemctl restart fail2ban
```
Скриншоты: меню «Сетевые службы» → «Правила Fail2ban» для каждой службы + содержимое /etc/fail2ban/jail.local.

## 13. Правила брандмауэра

Где: ispmanager → Администрирование → Брандмауэр .

Правила:

| № | Действие | Протокол | Порт | IP-адрес | Примечание |
|---|---|---|---|---|---|
| 1 | Разрешить | Все | Все | Ваш IP | Полный доступ |
| 2 | Запретить | TCP | 143 | 8.8.1.1 | Блокировка IMAP |
| 3 | Частично запретить | UDP | 80 | 0.0.0.0 | Разрешить только ваш IP и 15.15.4.5 |
| 4 | Запретить | Все | Все | 9.10.11.12 | Полная блокировка |

Для правила 3: выбрать действие «Частично запретить», протокол UDP, порт 80, в «Запрещённые IP» — 0.0.0.0, в «Доверенные IP» — ваш IP и 15.15.4.5.

Скриншоты: меню «Брандмауэр» + «Зависимые правила».
